# Design Doc: TODO CLI

## Problema
Usuarios precisam de uma ferramenta de linha de comando simples para gerenciar tarefas diarias.

## Solucao
CLI em Node.js que permite adicionar, listar e completar tarefas. Dados persistidos em arquivo JSON local.

## Funcionalidades

### 1. Adicionar tarefa
- Comando: `todo add "descricao da tarefa"`
- Cria tarefa com ID incremental, status "pendente", timestamp de criacao

### 2. Listar tarefas
- Comando: `todo list`
- Mostra todas as tarefas com ID, status e descricao
- Filtro opcional: `todo list --done` ou `todo list --pending`

### 3. Completar tarefa
- Comando: `todo done <id>`
- Marca tarefa como concluida com timestamp

## Decisoes tecnicas

- **Persistencia**: arquivo `~/.todo.json` (JSON simples)
- **Parser de argumentos**: process.argv manual (sem dependencias externas)
- **Output**: texto formatado no terminal com cores (chalk ou manual)
- **Testes**: vitest com mock do filesystem

## Estrutura proposta

```
src/
  index.js        # Entry point, parser de comandos
  todo.js         # Logica de negocio (add, list, done)
  storage.js      # Leitura/escrita do arquivo JSON
tests/
  todo.test.js    # Testes unitarios
  storage.test.js # Testes de persistencia
```
